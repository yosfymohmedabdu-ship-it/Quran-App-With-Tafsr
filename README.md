# تطبيق قرآن كريم مع التفسير | Quran Application with Tafsir
مشروع مفتوح المصدر لعرض سور القرآن الكريم مع تفسير مبسط للآيات.  
An open-source project to display the Holy Quran with simplified interpretation of verses.

## ✨ المميزات | Features
- عرض السور بترتيب المصحف | Display Surahs in order
- تفسير مبسط لكل آية | Simplified tafsir for each verse
- البحث عن السور والآيات | Search functionality

## 📲 طريقة الاستخدام | How to Use
1. افتح التطبيق | Open the app
2. اختر السورة من القائمة | Select a Surah
3. اقرأ الآيات مع التفسير المبسط | Read verses with tafsir
